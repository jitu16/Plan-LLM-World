#+TITLE: LLM World Simulation — Planning Repository
#+STARTUP: overview

* Purpose
Planning documents for an autonomous, multi-generational medieval-fantasy RPG world. The world should evolve without a player; optional player participation should not be required for its history to unfold.

* Status
Initial draft. No implementation code. The documents distinguish agreed decisions, tentative proposals, and unanswered questions.

* Editorial conventions
- Plain Org-mode planning documents; no implementation yet.
- AGREED means selected design direction; PROPOSED means a candidate, and OPEN means unresolved.
- Preserve past decisions and document changes in [[file:design-decisions.org][design-decisions.org]].
- The world engine alone determines physical truth and action outcomes.
